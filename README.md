# 알수없음 — 악마 위키

게임 속에서 단서를 찾는 플레이어용 도움말 형식 위키입니다. 이름, 결말, 해독 결과는 페이지에 싣지 않았습니다.

## 배포

GitHub Pages 대상 저장소는 `yiseh/404-wiki`이며, 기본 제공 주소는 `https://yiseh.github.io/404-wiki/`입니다. 별도 빌드 없이 `main` 브랜치의 루트에서 정적 파일을 제공합니다.

새 저장소에는 웹사이트 코드·이미지·README·로컬 실행 파일만 포함하며, `사전지식.md`와 작업용 `preview*` 이미지는 업로드하지 않습니다. 원본 프로젝트의 기존 Git 이력은 별도로 보존합니다. 원본 이미지 URL은 Git 파일명과 같은 NFC 형식으로 정규화했습니다.

## 열기

Finder에서 `start.command`를 두 번 클릭해 실행하고, 브라우저에서 아래 주소를 엽니다.

<http://127.0.0.1:4173/>

웹페이지를 보는 동안 실행된 터미널 창을 열어 두세요. 창을 닫거나 `Ctrl+C`로 서버를 종료하면 위 주소에 접속할 수 없습니다. 이미 같은 웹페이지 서버가 실행 중이면 시작 파일은 기존 접속 주소를 안내합니다.

시작 파일은 실행 위치와 관계없이 이 폴더를 제공하며, 다른 기기에 공개되지 않도록 `127.0.0.1`에만 연결합니다. Python 3가 필요하며, 별도의 패키지 설치나 빌드는 필요 없습니다. HTML·이미지·스타일·스크립트는 모두 로컬에 있습니다.

터미널에서 직접 실행하려면 다음 명령을 사용합니다.

```sh
./start.command
```

`index.html`을 일반 브라우저에서 직접 열 수도 있지만, 앱 내부 미리보기는 로컬 HTTP 주소를 사용하세요. 채팅의 파일 링크는 소스 파일을 열 수 있으므로 웹페이지 확인에는 위 접속 주소를 사용합니다.

## 접속이 안 될 때

- 연결이 거부되면 `start.command`가 실행 중인지 확인합니다.
- 주소의 포트가 `4173`인지 확인합니다. 출처 문서는 `http://127.0.0.1:4173/references.html`입니다.
- `4173 포트를 다른 프로그램이 사용`한다는 안내가 나오면 해당 프로그램을 확인합니다. 시작 파일은 기존 프로그램을 종료하지 않습니다.
- 파일을 수정한 뒤에는 브라우저를 새로고침합니다.

## 구성

- `start.command`: 로컬 웹페이지 서버 실행
- `index.html`: 악마에 관한 문헌 본문
- `references.html`: 별도 출처 및 참고 문헌 페이지 (구마 설명의 USCCB 공식 자료 포함)
- `styles.css`: Windows 98 도움말 창 스타일, 녹색 제목 표시줄·입체 도구 모음·트리 목차·종이 질감 본문, 반응형·다크 모드·인쇄 스타일
- `script.js`: 항목별 문서 탐색, 이전·다음 이동, 트리 목차·색인·검색, 창 최소화·최대화·닫기·복원, 글 크기·너비·색상 설정
- `assets/codex-gigas-devil.jpg`: 위키백과 참고 삽화, Wikimedia Commons 원본. 출처·퍼블릭 도메인 표기는 별도 참고 문헌 페이지에 기재
- `assets/references/{satan,lucifer,beelzebub,anomir,exorcism}.jpg`: 악마 네 종류와 구마 의식의 표시용 삽화
- `IMG/`: 사용자가 제공한 참고 이미지 원본 열 장
- `assets/references/`: 본문 표시용으로 용량을 줄인 JPEG 사본. 원본의 비율과 전체 구도를 유지하며, 클릭 시 `IMG/`의 원본을 새 탭에서 표시

왼쪽 트리 목차에서 글을 고르면 오른쪽 본문에 해당 항목이 열립니다. 폴더의 +/−를 눌러 하위 항목을 펼치거나 접고, 색인 탭에서는 가나다순으로 항목을 찾습니다. 검색 탭은 제목과 본문을 검색하며, `/`는 별도 검색창을 열고 `Esc`는 검색창이나 열린 패널을 닫습니다. 도구 모음과 본문 하단의 이전·다음 버튼으로 글을 이동합니다. 각 항목의 URL 해시와 참고 문헌의 직접 링크도 사용할 수 있습니다. 작은 모바일 화면에서는 도구 모음의 ‘목차’로 탐색 패널을 엽니다.

화면 설정은 상단의 ‘화면 설정’에서 엽니다. 외관 설정은 브라우저가 허용하는 경우 해당 브라우저에 저장됩니다. 제목 표시줄의 버튼으로 창을 최소화·최대화·닫을 수 있으며, 닫은 창은 바탕화면의 ‘도움말 서고 열기’로 복원합니다. 인쇄 시에는 모든 본문 항목이 함께 출력됩니다. 로컬 정적 파일 서버 외에 애플리케이션 서버, 로그인, 데이터 전송, 외부 폰트는 사용하지 않습니다. ASCII·모스부호·동서남북 표는 현재 문서에서 삭제된 상태입니다.

본문의 「악마 숭배」는 폐쇄된 사이비 교회의 방문 사진과 짧은 괴담을 소개하며, 고해성사에 관한 설명은 담지 않습니다. 「악마의 서」는 옛 삽화에 악마와 함께 등장하는 붉은 표지의 책이라는 설정을 짧게 소개하며, 역오망성의 형태를 별도로 설명합니다. 두 단락과 「진명에 대하여」의 익명 구마 기록은 게임 세계관의 창작입니다. 「엑소시스트와 구마」는 USCCB와 옛 『로마 예식서』를 참고하여 의식의 과정과 악마의 이름이 사용되는 전통을 설명하고, 영화 「콘스탄틴」의 구마 묘사를 짧게 소개합니다. 참고 자료는 `references.html`에 기재했습니다.

## 이미지 교체

제공된 이미지 열 장을 내용에 맞춰 배치했습니다. 「문헌 속의 악마」에는 군중과 악마의 삽화, 「악마 숭배」에는 폐쇄 후 촬영했다는 설정의 예배 공간과 부속 교실 사진, 「악마의 서」에는 책을 든 악마와 역오망성 문양을 넣었습니다. 「악마의 유형」에는 사탄·루시퍼·베엘제붑·아노미르 삽화를, 「엑소시스트와 구마」에는 중세 성화풍의 구마 의식 삽화를 배치했습니다. 이미지는 자르지 않고 원래 비율로 표시하며, 작은 화면에서는 세로로 배치합니다. 붉은 책의 기존 대체 도판은 책이 등장하는 참고 삽화로 교체했습니다. 참고 이미지의 성격은 `references.html`에 함께 안내합니다.

이미지를 교체할 때는 `index.html`의 경로·대체 텍스트·캡션과 `references.html`의 안내를 함께 수정합니다. `IMG/` 원본을 바꾸면 `assets/references/`의 표시용 사본도 갱신해야 합니다.

‘악마의 유형’의 삽화는 너비 110px, 작은 모바일 화면에서는 75px로 표시합니다. 구마 의식 삽화는 본문 오른쪽에 참고 도판으로 배치합니다. 추가한 다섯 장은 용량을 줄인 JPEG로 제공하며 클릭하면 `IMG/` 원본을 엽니다.

## 내용의 출처

사용자가 제공한 사전지식 파일은 RTF 형식으로 저장되어 있어 원본을 수정하지 않고 텍스트로 변환하여 전체를 읽었습니다. 그 설정에 근거한 허구와 실제 참고 문헌은 별도 참고 문헌 페이지에서 구분했습니다. 나무위키는 접근할 수 없어 사용자 확인에 따라 사용하지 않았습니다.
